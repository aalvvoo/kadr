# Кадр

Простой видеоредактор в браузере: фото и видео на холсте, своя аудиодорожка, скорость, выгрузка в MP4 720p, 1080p и 4K.

Всё работает на стороне браузера, файлы никуда не загружаются.

## Где хранятся проекты

Проекты лежат в хранилище браузера (IndexedDB) для адреса этого сайта. Они не видны в другом браузере или на другом устройстве и пропадут, если очистить данные сайта.

Чтобы не терять работу, сохраняйте **«Копию проекта»** — это `.zip` со всеми исходниками и настройками. Открыть его можно кнопкой **«Открыть файл проекта»**.

## Браузеры

Выгрузка MP4 работает в свежих Chrome, Edge, Opera и Safari 17+.
